          การเชื่อมต่อ: เปิด Firebase Console → สร้าง Web App → คัดลอก Firebase Config → กด FIREBASE SETUP แล้ววาง JSON. จากนั้นเปิด Email/Password ใน Authentication และสร้างบัญชีเจ้าหน้าที่ที่ต้องการให้เข้า Cloud. การซิงก์: Firestore listener จะส่งประกาศ/ภารกิจ/ข้อมูลล่าสุดไปทุกหน้าที่ออนไลน์. ความปลอดภัย: ตั้ง Firestore Rules จากปุ่มคู่มือก่อนเปิดใช้งานจริง.
          

          13 // DAILY MISSION BOARD / LIVE
          ประกาศภารกิจประจำวันให้เจ้าหน้าที่ทุกระดับ • ทุกเครื่องที่เชื่อม Firebase จะรับภารกิจฉบับเดียวกันทันทีผ่าน realtime listener • ประวัติการประกาศยังคงอยู่และไม่ถูกลบจากปุ่มผู้ใช้.
          NORMAL = ข้อมูลทั่วไป • HIGH = สำคัญ/ด่วน ใช้สีส้ม • URGENT = แจ้งเตือนเร่งด่วนมาก ใช้สีแดงและแสดงคำเตือนชัดเจน
          ลำดับการแสดง: URGENT สีแดง → HIGH สีส้ม → NORMAL ตามลำดับเวลา. ปุ่ม × ซ่อนเฉพาะเครื่องนั้นเท่านั้น; ไม่มีปุ่มยกเลิกประกาศ.
